# 注册验证服务调研（2026-10-25）

当前账号服务使用邮箱、手机号和密码注册，但尚未证明邮箱或手机号属于注册者。注册与登录已有数据库共享限流。若启用邮件或短信验证码，必须在服务端完成发送、限流、过期、单次消费和注册状态绑定；前端出现输入框本身不构成验证。

| 能力 | 可选服务 | 已公布费用 | 启用条件 |
| --- | --- | --- | --- |
| 邮件验证码 | 阿里云邮件推送 Direct Mail | 主账号累计免费 2,000 封，每日最多免费 200 封；其后按量 2 元 / 1,000 封；1 万封资源包 19.98 元 / 6 个月 | 开通服务、配置自有发信域名与 DNS、发信地址及 API 凭据 |
| 邮件验证码 | 腾讯云邮件推送 SES | 账号累计免费 1,000 封；其后 0.0019 元 / 封 | 开通服务、验证发信域名及配置 API 凭据 |
| 国内短信验证码 | 阿里云短信服务 | 月用量不超过 10 万条时按量 0.045 元 / 条；1,000 条套餐包 50 元 | 中国大陆公司资质、审核通过的短信签名和模板；国际短信另行计价 |
| 国内短信验证码 | 腾讯云短信 SMS | 1 万条套餐 470 元 / 2 年，即 0.047 元 / 条；官方说明新用户可领取少量试用短信 | 实名认证、签名与模板审核；国际短信按目的地另行计价 |
| 滑动拼图人机验证 | 阿里云验证码 2.0 | 中国内地按量 0.005 元 / 次，非中国内地 0.007 元 / 次；前三个验证场景免场景费 | 开通服务、创建场景、前端挑战与服务端票据校验 |
| 滑动拼图人机验证 | 腾讯云天御验证码 | 新用户 20,000 次 / 7 天测试包；正式包 30,000 次 / 年 300 元，超包后付费 0.005 元 / 次（需先购买并开通） | 实名认证、创建验证场景、前端挑战与服务端票据校验 |

价格只计发送或验证请求；域名、服务器、国际短信、失败重试与可能的附加功能另计。以 1,000 次大陆注册各发一封邮件、一条短信和做一次拼图估算：阿里云按量费用约 2 + 45 + 5 = **52 元**，前提是邮件免费额度已用完，且全部请求各只发生一次。实际账单以控制台为准。

建议先选择同一云账号下的邮件、短信和验证码服务，减少账号与密钥管理；若更重视拼图试用，可考虑腾讯云的 7 天测试包。服务端的顺序应是：完成滑动拼图 → 验证票据 → 按 IP、目的地址和设备限流 → 发送验证码 → 在数据库保存验证码摘要与 5 分钟有效期 → 单次消费后创建账号。发送失败时不能宣称已发送，验证失败不能创建已验证账号。拼图还应提供非拖动方式，兼顾键盘和行动不便用户。

本轮直接完成无需供应商账号的表单、手机号归一化和持久化花名池。账号 ID 唯一，用户名允许重名；花名池初始 1,000 个，领取时标记已使用，剩余不足 100 时 worker 调用现有模型补充一批，并用本地候选库补齐到 1,000 个。模型调用可能按当前模型服务商计费，单次花名领取不会调用模型。邮件、短信及第三方拼图需要发信域名、短信主体/签名/模板、应用 ID 与服务端密钥；这些账号资源尚未在项目中配置，因此当前页面明确显示“尚未验证”，避免把形式上的验证码误称为有效验证。注册接口继续执行现有数据库限流。

当前环境配置的是 DeepSeek `deepseek-flash`。官方按百万 token 标价：非高峰输入缓存未命中 $0.15、输出 $0.60；高峰分别 $0.30、$1.20。花名池每次补充最多请求模型一次，假设约 5,000 输入 token、2,000 输出 token，则单次约 **$0.00195–$0.00390**；实际按请求返回的 token 用量计费，输出不足的部分由本地候选库补齐。首次部署的 1,000 个花名完全由本地候选库生成，不产生模型费用。
