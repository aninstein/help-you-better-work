# 个人员工实施与验收记录

日期：2026-10-25。分支：`feature/deerflow-agent`。

## 已实施

- 新流量入口为 `app.employee.web`，旧 Demo 认证、自研逐题决策图和审核/补答链不再挂载。
- 官方 DeerFlow 2.1.0 / `e9074b7126833b5ca4739bcedcbbed01b211246c` embedded lead agent；依赖与源码快照锁定。版本化个人员工 Prompt + 会议 Skill；保留官方工具、子任务、记忆与上下文压缩。
- 独立交互 worker 和问题投影 worker。主回复完成后原子提交结果并排入独立投影，投影失败不会阻塞聊天。同会话输入依序排队；记录、修订、幂等请求、事件游标、显式取消、租约 fencing 与原生 checkpoint 恢复由 MySQL 保存。
- MySQL 8.4.7 独立容器；schema v4。实现官方同步/异步 Saver、pending writes、Store、MemoryManager 插槽，禁止 SQLite/文件权威存储回退。长文使用 LONGTEXT，时间戳使用 DOUBLE。
- 手机/邮箱/密码注册、Argon2id、有状态 HttpOnly Cookie、CSRF/Origin、限流、强制首次改密、退出、权限版本和撤权失效。默认 Talker；Hinter Admin 授权、监管、私有备注、旧空间显式绑定；最后管理员事务保护。
- 新登录/注册/聊天/管理界面保留现有配色。账号状态右上角展示，按服务端 capabilities 显示入口；草稿按用户/空间/会话隔离；事件增量重放与记录分页加载。
- 上传转写、PCM 协议 3 通话、帧缺口检测、挂断尾句保存、转写修订、回复朗读。音频打断与 Run 取消分离。模型缓存位于持久卷；兼容固定 PyAV 的显式解码。在线 TTS 失败时使用离线 eSpeak 朗读。
- Compose、迁移、bootstrap、本机/外部模型启动、就绪检查、备份、显式覆盖恢复与管理员运维恢复脚本。

## 运维交接与范围

- 当时的服务入口为 `http://127.0.0.1:8818`；验收所用旧管理员凭据只保存在本机私密文件，未写入本文或 Git。当前新部署由操作者自行设置登录名和密码。
- 历史空间保留为 `unclaimed_legacy`，由实际管理员将其绑定到注册账户；不会自动认领。原 `backend/data` 和只读快照保留。
- `summary` 仍返回明确的 422 未支持响应；没有把问题提取冒充摘要功能。没有恢复历史逐题扫描补答。
- 当前默认外部模型；可选本地 Ollama 的模型卷已准备。外部模型和在线语音服务的健康不能仅凭容器存活推断。
- 用户真实麦克风、耳机回声和不同浏览器的声学效果需要在实际设备上体验；自动化使用音频样本和协议帧验证 IO 与授权。
- 上述运行证据及截图保存在本机 `.runtime/`，该目录与所有凭据、音频不提交。备份恢复脚本始终要求明确覆盖参数；普通停止保留卷。
