# 将 Hinter 短输入与原问题及补充任务组合

## Why
Hinter 的“200”“50%”或“这个不能说”需要绑定语义对象。只保留原始 Hint 字符串会丢失缺什么信息、数值属于谁、应怎样生成回答等上下文。

## What Changes
- 在已有拆题调用内生成私有的人工补充任务：问题概述、需要补充什么，以及服务端定义的英文回答合成要求。
- 显示这份任务，Hinter 可以只填数值；将原始输入、提取的问题、补充任务、Hint 原文和类型组成结构化输入。
- 同步结构化关联到 Talker 的私有 Wiki 和后续生成，事实、禁止事项与参考资料保持语义区别。
- 唯一待补题可自动承接裸数值；多个候选时要求选择对应题，不将一个裸数值套用多题。

## Scope
三入口共用现有生成链路，保留默认自动回复与少量待补，不增加一轮 Agent 检索、审批门禁或长期测试题库。
