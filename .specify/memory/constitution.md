# Duet AI Constitution

## I. 按模式控制回答
文本、上传语音和实时通话默认自动回答，问题记录与人工提示不阻塞普通回复。只有明确人工确认规则、确需人工提供的真实依据或无法消解的适用约束冲突进入逐题待补。哲学、新话题、一般歧义和处理失败不默认转人工；歧义向 Talker 澄清，危险协助自动拒绝。历史私有草稿保持私有，不批量发布。

## II. 确定性控制面
业务状态、转换条件、重试、超时、幂等、租约与补偿由自研状态机控制。LangChain 仅用于模型调用、structured output、Prompt/Tool abstraction；不得让模型或 Agent 框架决定业务状态跳转。一期不引入 DSH、LangGraph 或多微服务。

## III. 隔离优先
所有客户数据读写必须同时绑定 `tenant_id` 与 `customer_id`。记忆召回优先级固定为当前轮次 > 短期 > 长期。跨租户或跨客户内容进入上下文属于 P0 安全事故。

## IV. 后端角色投影
权限不是 UI 隐藏。后端必须在序列化层按角色执行字段白名单投影；Talker 永不收到 hint、reviewer、审核备注、内部 memory evidence/ID、Prompt 或 Tool trace，包括 HTTP、WebSocket、SSE、日志和错误响应。

## V. 单活动输出与可取消生成
同一问题最多一个有效自动输出，每个会话的声音串行播放；不同问题可独立准备，慢工具不占据输出锁。已公开内容不可整答 reset 或从头重播，过期 worker 不得提交结果。

通话按 call/epoch 和 response/segment 控制输出，Talker 插话、Hinter 纠正或挂断撤销相关输出。Hinter 为独立通道，先持久保存提示，再异步投影 LLM Wiki；生成前读取，发布时遵守最新适用约束。禁止项直接遵守，不反复请人工放行；自动回复不注册任意 bash/MCP 或外部写入工具。

## VI. 音频可追溯且可降级
保留原音频与 STT final transcript。AI 生成中按完整短句持续公开、合成和播放，不等待整答完成；所有阶段支持停止与有效插话。实际播放通过段级确认记录，未播尾部不得记成已说。浏览器拒绝自动播放时降级为显式播放，不丢失文本答案。完整音频文件仅作后续归档。

## VII. 可验证规格驱动
优先完成功能。用必要的构建和代表性实际运行核验自动回复、Hint、流式语音与打断，不为本轮扩建题库、审核平台或额外门禁，也不要求迁就历史逐题审核测试。
